# Controls

Hover over a button, card, stack, or region for 0.7 seconds to see its action and keys. Keyboard focus also shows the hint. Open **?** (or press **H** / **?**) for the guide in the app.

The players/tribes panel automatically opens tribe choices only when it becomes **your** turn to choose. Opponents' turns and spectator playback leave your chosen panel alone. Press **S** to switch manually.

## Board

| Action | Input |
| --- | --- |
| Inspect race, trait, piece, or region | Ctrl/Cmd + click, or I then click |
| Open wiki | W |
| Exit Inspect | Escape |
| Choose a tribe from the visible market | 1–9, on your tribe-choice turn |
| Cycle reserve pieces | G |
| Select a piece or region | Click, or Tab then Enter/Space |
| Return a selected region's troops before conquest | A |
| Return one selected piece during redeployment | A |
| Clear selection | F or Escape |
| Decline / redeploy / finish turn | D / R / E |
| Save / rollback / leave | Shift+S / Shift+R / Shift+L |
| Dismiss an error | C |
| Pan / zoom map | Drag / scroll |

Actions are available only in the appropriate phase and on your turn. Typing, browser shortcuts, key repeat, and modal dialogs do not trigger background game actions. Inspect mode also blocks action shortcuts.

## Bot playback

The host can pause/resume with **Space**, step back/forward with **Left/Right** while paused, and change speed with **− / +** (**=** also speeds up). A focused button still uses its normal Enter/Space action. On the results dialog, Left goes back when history is available; Shift+L leaves.

## Lobby

| Action | Input |
| --- | --- |
| Switch Saves / Races & Traits | S |
| Start game as host | P |
| Browse saved maps/games | V |
| Leave room | Shift+L |
| Play / watch as host | O |
| Add bot / use bot-compatible rules | B / Shift+B |
| Standard / Underground preset, with choices tab open | N / U |

The preset buttons above the choices change the full setup together: **Standard** selects non-Underground expansions and Generated Map; **Underground** selects Underground races, traits and powers and the two-player Underground map. Manual changes show **Custom setup**. A two-player preset cannot displace occupied seats. Presets clear a selected save. New rooms start in Standard mode; existing rooms and saved games retain their settings.

Use **Tab / Shift+Tab** to reach other controls; Enter/Space activates buttons, Space toggles checkboxes, and arrow keys change select menus. Destructive actions such as deleting a save or removing a player have no global single-key shortcut.
